Huffman Tree

二叉树 n个带权叶结点
树的带权路径长度 Weighted Path Length of Tree WPL
从根结点到各个叶结点的路径长度和相应叶结点权值乘积之和

WPL=∑wl

WPL最小的二叉树 霍夫曼树Huffman Tree

构造

  1. 初始化：由给定的n个权值构造n个只有一个根结点的二叉树集合F
  2. 选取、合并：从F中选取根结点最小的两棵，分别作为左右子树构造一棵新二叉树，根结点为左右结点权值之和
  3. 删除、加入：从F中删除作为左右子树的两颗二叉树，并将新建立的二叉树加入到F中
  4. 重复2、3，当集合中只剩下1棵树时结束

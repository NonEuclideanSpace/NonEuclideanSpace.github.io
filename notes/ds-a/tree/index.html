    递归遍历
class Node{
public:
	int val;
	Node* left;
	Node* right;
	Node(int x):val(x),left(nullptr),right(nullptr){}
};
void traverse(Node* root){
	if(root==nullptr)return;
	//前序位置
	traverse(root->left);
	//中序位置
	traverse(root->right);
	//后序位置
}

递归遍历的顺序 函数访问结点的顺序确实是固定的

在traverse中不同位置放代码
即 三种位置的关键在于执行时机的不同

  • 二叉搜索树的中序遍历，结果是有序的

缺点 无法知道当前结点在第几层 简单但不常用

写法二

void traverse(Node* root){
	if(root==nullptr)return;
	queue<Node*>q;
	q.push(root);
	
	int depth=1;
	
	while(!q.empty()){
		int size=q.size();
		for(int i=0;i<size;i++){
			Node* cur=q.front();
			q.pop();
			cout<<depth<<endl;
			cout<<cur->val<<endl;
			if(cur->left!=nullptr)
				q.push(cur->left);
			if(cur->right!=nullptr)
				q.push(cur->right);
		}
	}
	depth++;
}

写法二，每向下一层，depth+1，可以理解为每条边权重为1
如果每条边权重可以为任意值

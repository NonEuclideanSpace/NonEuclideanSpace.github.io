RLHF and RLVR in LLM Post-Training

摘要

大语言模型在海量无标注文本上通过预测 next token 完成预训练后，虽然掌握了广泛的语言规律与世界知识，但其原始生成目标与人类实际交互需求，以及复杂逻辑推演目标之间仍存在显著偏差。围绕后训练（Post-Training）阶段如何利用反馈信号重塑模型行为，研究范式先后经历了从基于人类反馈的强化学习（Reinforcement Learning from Human Feedback，简称 RLHF）到基于可验证奖励的强化学习（Reinforcement Learning with Verifiable Rewards，简称 RLVR）的重要演进。本文系统梳理这两类后训练强化学习方法提出的核心动机、技术脉络、内在联系与适用边界。在基础方法层面，本文首先阐明自回归文本生成向序列决策过程的转化逻辑，分析策略梯度、优势估计、近端策略优化以及参考策略分布约束在稳定高维语言空间优化中的具体作用。随后，本文沿着从主观偏好对齐到客观结果验证的演进线索，剖析 RLHF 如何借助成对人类偏好与奖励模型解决开放域任务难以规则化评价的难题，探讨直接偏好优化对训练流程的简化及其离线分布局限，并揭示代理奖励过度优化这一促使研究转向客观验证的深层原因；继而深入考察 RLVR 如何利用数学答案核验与代码单元测试等确定性验证程序消除奖励模型偏差，以及群组相对策略优化、动态采样与无偏损失修正等方法如何支撑无监督微调冷启动下的长链推理演化。在此基础上，本文从奖励来源、过程与结果反馈粒度、评估可靠性及多阶段协同四个维度对比两类范式的利弊互补关系，并进一步围绕近期关于“RLVR 究竟只是提高已有路径采样效率，还是实质扩展模型推理能力边界”的学术争论展开深入辨析，总结持续强化学习所需的 token 级探索维持、训练步数扩展、混合难度隐式课程以及跨学科生成式验证机制，最后展望大语言模型强化学习后训练的未来研究方向。

1 引言

1.1 研究背景：从语言建模到推理能力+提升偏好对齐

现代大语言模型（Large Language Models，简称 LLMs）的能力构建始于大规模自回归语言建模预训练（Pre-Training）。在预训练阶段，模型接收互联网网页、书籍、学术文献与程序代码等海量文本序列，在给定前文 token 的条件下最大化下一个 token 的预测对数似然。随着模型参数规模与预训练语料规模的持续扩大，这一看似简单的统计预测目标使模型习得了丰富的语法结构、跨学科事实知识以及初步的上下文模式归纳能力。然而，预测语料库中最可能出现的后续文本并不等同于按照用户意图高质量地完成任务，更不等同于执行严密可靠的多步逻辑推理。一方面，原始预训练语料混杂着质量参差不齐的表述、事实性错误乃至有害内容，基座模型在面对用户提问时往往倾向于机械续写题目而非直接作答，难以自动遵循人类在有用性（Helpfulness）、真实性（Honesty）与无害性（Harmlessness）上的综合偏好[1,2]。另一方面，面对数学竞赛证明、复杂算法编程与科学分析等高难度问题，模型需要在给出最终结论前展开长跨度的中间推导、假设检验与自我纠错，而自然语料中很少完整记录人类思考过程中反复试错与修正的轨迹，仅靠模仿静态文本的下一 token 预测难以充分激发深层推理潜力[3,2]。

为了弥补预训练语言建模目标与下游实际需求之间的差距，后训练（Post-Training）逐渐从辅助性的微调步骤演变为决定大语言模型能力表现的核心阶段。早期也是最直接的后训练手段是监督微调（Supervised Fine-Tuning，简称 SFT），即由人工撰写或筛选高质量的“指令—回复”示范样本，继续使用交叉熵损失训练模型模仿标准回答。监督微调能够以较低的计算成本教会模型理解对话格式与基本指令要求，但其固有的局限性也十分突出。首先，人工编写高质量长篇回答或严密多步推导过程的成本极高，示范数据的规模与复杂度受限于人类标注者的时间与专业水平；其次，监督微调在训练时强制模型在每一个 token 位置拟合单一参考序列，模型只能被动记忆外部示范的表面分布，既无法从自身的错误生成中获知“错在何处”，也难以在自身预测分布内主动探索比人工示范更优的求解路径[1,2]。要让模型在缺乏逐词标准答案的场景下学会权衡回答优劣，或者在多步求解中通过自主尝试发现有效策略，就必须引入强化学习（Reinforcement Learning，简称 RL），使模型在自主采样生成完整回复后根据整体反馈信号调整生成概率。

如图 1 所示，大语言模型强化学习后训练的发展历程清晰地呈现出两条相互衔接又各有侧重的技术主线[2]。第一条主线致力于提升人类偏好对齐水平，其代表范式是基于人类反馈的强化学习（Reinforcement Learning from Human Feedback，简称 RLHF）。在开放式问答、摘要撰写、创意写作与安全拒答等日常交互场景中，回答的优劣往往取决于表达清晰度、信息完备度与价值导向等主观综合维度，无法用固定程序规则直接打分。为此，Christiano 等人[4]与 InstructGPT[1]确立了“先采集人类对成对候选输出的主观偏好比较、训练神经网络奖励模型拟合人类评判标准，再通过强化学习最大化奖励模型评分”的技术路线，随后 Rafailov 等人提出的直接偏好优化（Direct Preference Optimization，简称 DPO）[5]进一步利用最优策略与奖励函数之间的解析映射省去了显式奖励训练环节，大幅降低了偏好对齐的工程门槛。

第二条主线则聚焦于突破复杂逻辑与科学任务的推理能力上限，其核心驱动范式是基于可验证奖励的强化学习（Reinforcement Learning with Verifiable Rewards，简称 RLVR）[6,7,3]。随着研究重心从日常对话转向竞赛级数学求解与高难度代码生成，传统 RLHF 所依赖的神经网络奖励模型暴露出严重的评估噪声与奖励欺骗（Reward Hacking）问题：在漫长的多步推导中，参数化的奖励模型极易被表面排版工整但关键算式错误的文本误导，导致策略模型在强化学习后期通过迎合评估漏洞获取虚假高分[8,3]。针对数学与编程等“求解过程复杂但最终结果客观可查”的任务属性，Tülu 3[6]、DeepSeekMath[7]以及 DeepSeek-R1[3]等代表性工作不再依赖主观偏好拟合，而是直接采用符号数学等价检验器、编译器与单元测试套件等确定性程序对模型最终输出给出精准无偏的验证反馈。实验表明，这种高可靠性的客观反馈支撑了更大规模的在线强化学习计算投入，使模型在无需人工逐步标注推导过程的前提下，自发演化出拉长思维链（Chain-of-Thought，简称 CoT）、检验中间结论以及推翻错误分支重新推导等复杂推理行为，从而开启了测试时计算扩展与训练时强化学习扩展协同演进的新阶段[3,2]。

1.2 本文范围与核心问题

本文聚焦于大语言模型后训练阶段中 RLHF 与 RLVR 这两类核心强化学习范式，旨在厘清二者从理论建模、算法设计到工程实践与前沿争论的完整逻辑脉络，而非罗列孤立的模型细节或工程技巧。为了便于读者准确把握全篇主线，本文围绕以下四个层层递进的核心问题展开论述。

第一个核心问题是：原本执行离散 token 自回归预测的大语言模型，如何在统一的序列决策框架下接受标量奖励信号并实现稳定的参数更新？对此，第 2 节将阐明文本生成过程与马尔可夫决策过程的对应关系，剖析策略梯度定理、广义优势估计与近端策略优化（Proximal Policy Optimization，简称 PPO）[9]如何解决长序列高方差信度分配难题，并重点解释为何强化学习后训练普遍需要引入参考策略与分布散度约束来防止语言退化与过度优化[8,10]。

第二个核心问题是：面对无客观标准答案的主观交互任务与有确定性检验标准的客观推理任务，RLHF 与 RLVR 各自基于怎样的动机设计了不同的反馈获取机制与优化算法，又分别面临哪些固有局限？第 3 节将深入分析 RLHF 从成对偏好采集、Bradley-Terry 奖励建模[4,1]到 DPO 隐式奖励重参数化[5]的演化逻辑，剖析偏好标注噪声、离线分布偏移与代理奖励过度优化定律[8,10]对其扩展性的制约；第 4 节则转向 RLVR，阐述确定性验证函数的构造条件[6]、群组相对策略优化（Group Relative Policy Optimization，简称 GRPO）省去独立价值网络的动机与机制[7]、Tülu 3 与 DeepSeek-R1 系列多阶段训练流程的设计考量[6,3]，以及解耦截断与动态采样策略优化（Decoupled Clip and Dynamic sAmpling Policy Optimization，简称 DAPO）[11]和无偏群组相对策略优化（Dr. GRPO）[12]如何针对熵坍缩和长度偏差改进优化器。

第三个核心问题是：RLHF 与 RLVR 在整个后训练体系中究竟是替代关系还是互补关系，反馈粒度与奖励可靠性如何共同决定两者的协同方式？第 5 节将从奖励来源与适用任务边界出发，引入结果监督与过程监督这一正交的反馈粒度划分维度[13]，结合大规模训练中神经奖励模型的失效实证[3]，论证现代旗舰模型如何将客观可验证强化学习与人类偏好对齐有机整合在同一后训练流水线中[6,3]。

第四个核心问题是：近期引发广泛学术争论的“RLVR 究竟是否真正扩展了基座模型的推理能力边界”，应当如何在严谨的评估体系与训练动力学视角下加以理解？第 6 节将系统梳理基于多次采样通过率（Pass@k\mathrm{Pass@}kPass@k）与兼顾推导过程正确性的 CoT-Pass@k\mathrm{CoT\text{-}Pass@}kCoT-Pass@k 评估方法[14,15]，对比“仅压缩分布提升采样效率”[14]与“长程训练及隐式激励实质拓展求解边界”[16,15]两派观点的实证依据，进一步从 token 级低概率探索保护[17]、训练时长与参考策略重置[16]以及混合难度数据诱导的由易到难隐式课程[18]三个方面揭示持续强化学习的成立条件，并探讨如何借助基于参考答案的生成式软奖励验证器将 RLVR 推广至医学、法律与社会科学等自由文本领域[19]。最后，第 7 节对全文核心认识进行总结，并展望大语言模型强化学习后训练的未来研究方向。

2 大语言模型 RL 后训练的基本框架

2.1 从文本生成到序列决策

要将强化学习引入大语言模型后训练，首先需要解决一个建模层面的基本问题：大语言模型的本质是一个在固定词表 V\mathcal{V}V 上按顺序逐个输出 token 的条件概率分布，而强化学习处理的是智能体（Agent）在环境（Environment）中通过多步交互最大化累积回报的序贯决策问题。二者之所以能够无缝统一，关键洞见在于自回归文本生成的每一步 token 采样本身就是一次依赖历史上下文的离散动作选择[2,12]。

3 RLHF：从人类偏好中学习

3.1 人类反馈的采集与偏好奖励模型

强化学习之所以长期局限于棋类博弈与规则明确的模拟控制环境，根本原因在于绝大多数现实世界任务无法手工编写精确的标量奖励函数。以大语言模型面对的开放式摘要撰写、多轮情感支持、复杂概念解释以及伦理安全应对为例，一段回答的好坏同时取决于事实准确性、条理清晰度、语气得体程度以及潜在危害规避等多个主观维度，任何基于词频统计或表面重叠率（如 BLEU、ROUGE）的手工评价指标一旦被模型当作强化学习目标直接最大化，都会迅速诱发违背人类真实意图的畸形文本。为了打破奖励函数难以显式形式化的限制，Christiano 等人[4]提出了从人类偏好中开展深度强化学习的经典框架，确立了一条关键洞见：尽管人类很难为单条复杂行为轨迹直接给出跨样本一致的绝对分值，也难以亲自示范最优决策序列，但当面对同一问题下的两条候选结果时，人类能够以极低的认知负担且较高的信度判断“哪一个结果更好”。

3.2 经典训练流程：以 InstructGPT 为例

如果说早期偏好学习验证了“用奖励模型替代手工奖励”的可行性，那么 Ouyang 等人提出的 InstructGPT[1]则真正将这一思想工程化为现代大语言模型后训练的标准三阶段流水线，首次在百亿至千亿参数规模上证明：模型能否让真实用户满意，主要取决于后训练阶段的意图对齐质量，而非单纯取决于预训练参数规模的盲目扩张。

在实际推进第三阶段强化学习时，InstructGPT 发现了一个极具普遍意义的现象：单纯最大化人类对话偏好奖励并施加 KL 惩罚，虽然能大幅提升开放式指令遵循表现，却会导致模型在多项传统公开自然语言处理基准（如问答、阅读理解与翻译任务）上的零样本或少样本准确率出现明显下滑，文献将其称为“对齐税”（Alignment Tax）[1]。之所以产生对齐税，是因为对话偏好强化学习过度强化了特定交互句式，对预训练阶段习得的广泛通用分布造成了局部遗忘。为了消除这一负面效应，InstructGPT 在标准 KL 正则化强化学习目标之上混入了原始预训练语料分布 Dpretrain\mathcal{D}_{\mathrm{pretrain}}Dpretrain​ 上的自回归对数似然梯度，构造出著名的 PPO-ptx\mathrm{PPO\text{-}ptx}PPO-ptx 联合优化目标[1]：

3.4 主要局限

纵观整个 RLHF 技术体系（无论采用显式奖励模型的在线 PPO 还是隐式奖励重参数化的离线 DPO），尽管它在对齐人类日常交流偏好与安全规范方面表现卓越，但当业界试图将其进一步推向更高训练算力规模以及更严密的逻辑推理任务时，其底层机制暴露出四项难以仅靠微调算法细节彻底根除的结构性局限[8,10,3]。

第一项局限在于人类偏好数据采集的高昂成本与固有认知偏差。在日常闲聊或简短摘要任务中，普通标注员可以在数分钟内完成成对回复比较；但当问题涉及研究生水平的数学定理证明、大型软件工程跨文件调试或前沿生物医学文献推理时，雇佣具备相应专业能力的人类专家逐行核查两条数千词推导过程的真伪，在时间与资金上都难以实现百万量级的规模扩展[6,3]。更为棘手的是，当任务难度超出标注员的即时验证能力时，人类反馈会不可避免地退化为对表面文风的偏好——标注员更容易青睐排版清晰、语气自信、篇幅详尽但暗藏细微逻辑谬误或事实幻觉的回答，而给简短生硬却完全正确的回答打出低分，这种系统性标注偏差会直接误导模型习得迎合表象而非追求事实真值的生成倾向[1,10]。

4 RLVR：从可验证结果中学习

4.1 可验证奖励的构造与适用条件

面对 RLHF 中神经网络奖励模型难以规避的评估噪声与过度优化失效，研究者重新审视了不同下游任务的评估属性差异：文学创作与日常对话等开放域任务固然缺乏唯一标准答案，但在数学解题、算法编程、形式逻辑推演以及带明确格式约束的指令遵循任务中，虽然要求模型从零构造出一条正确的长跨度解答过程较为困难，一旦模型给出了候选输出，检验该结果是否正确却可以通过确定性的计算机程序精确完成。基于这一“求解困难而验证客观”的不对称特性，Tülu 3[6]明确将这一技术路线总结为基于可验证奖励的强化学习（Reinforcement Learning with Verifiable Rewards，简称 RLVR），即彻底用无参数的确定性验证函数（Deterministic Verifier）替代由人类偏好训练出的神经网络奖励模型，直接依据客观真伪检验结果向强化学习算法提供反馈信号[6,3,2]。

如图 11 所示，在 RLVR 框架中，训练数据集由问题提示 xxx 与对应的客观验证准则（如标准参考答案 aaa 或测试用例集合）构成。当策略模型 πθ\pi_\thetaπθ​ 生成完整回复 yyy 后，外部确定性验证器 v(x,y,a)v(x, y, a)v(x,y,a) 对输出执行自动化核验。在实际系统中，可验证奖励通常由结果准确性奖励与结构格式奖励两部分协同组成[6,3,2]：

用如此简洁的规则函数取代复杂的深度神经网络奖励模型，看似在奖励表达细腻度上做了减法，实则在训练动力学上带来了决定性的优势。由于确定性验证器不包含任何拟合误差，无论策略模型在数千步强化学习迭代后偏离初始分布多远，只要最终答案算错或代码未通过测试，模型就绝无可能依靠拉长篇幅、堆砌华丽辞藻或模仿权威语气换取任何虚假正反馈。这种对表面风格投机的天然免疫力，使得强化学习首次能够在极高的训练算力预算下安全运行，迫使策略模型将全部参数更新方向集中在真正提高最终解答准确率的内部推理计算上[3,2]。

当然，这一范式也具有严格受限的适用边界，综述文献将其概括为“验证器法则”（Verifier's Law），即强化学习在某一任务上取得突破的难易程度直接取决于该任务可被客观、快速、自动化验证的程度[2]。具体而言，标准 RLVR 的高效运转必须同时满足四项前提条件：其一，任务必须存在无歧义的客观正确性标准，这使其天然排除了创意写作、价值伦理权衡或开放式方案建议等主观任务；其二，验证过程本身必须轻量化且支持高并发并行执行，如果在科学仿真或大型系统编译中单次验证耗时数十分钟，在线强化学习的采样吞吐将被严重拖垮；其三，答案空间应当足够丰富以抑制盲目猜测，例如在仅有四个选项的选择题或“是/否”判断题中，模型即使推理过程完全混乱也有较高概率蒙对答案并获得正奖励，从而污染梯度信号[15]；其四，基座模型在初始状态下对该难度问题必须具备非零的偶然答对概率，否则在一批采样全部得零分的情况下，二值终端奖励无法提供任何指向正确方向的梯度信息[12,18]。

4.3 代表性训练流程：Tülu 3、DeepSeek-R1-Zero 与 DeepSeek-R1

从工程落地与科学认知演进的角度看，RLVR 如何嵌入大语言模型整体后训练流水线，在短短一两年内经历了从“多阶段对齐末端的专项增强”到“脱离人工示范直接激发原生推理”，再到“可验证推理与通用人类对齐全流程融合”的三次标志性跃迁，其代表作分别是 Tülu 3[6]、DeepSeek-R1-Zero 与 DeepSeek-R1[3]。

首先是 Lambert 等人构建的全开源后训练标杆 Tülu 3[6]，其整体架构如图 13 所示。在 Tülu 3 的设计逻辑中，RLVR 被定位于标准指令微调与偏好对齐之后的第四阶段专项精细调优：团队首先在近百万条精心去重与配比的指令集上执行监督微调赋予模型多任务基础能力，随后开展大规模 DPO 偏好对齐塑造通用对话质量，最后针对 GSM8K、MATH 数学求解与 IFEval 精确格式约束遵循这三类具备确定性验证程序的任务，启动带 KL 惩罚的在线 PPO 训练（正确赋予奖励 α=10\alpha=10α=10，错误赋予 000）[6]。Tülu 3 的实践验证了在已经完成偏好对齐的模型末端追加轻量级 RLVR，能够在不破坏通用对话能力的前提下稳定提升目标可验证基准得分。然而，受限于仅在短回复对齐模型末端做局部微调且保留较强的参考分布约束，这一模式下的模型基本维持了原有的作答篇幅与固定解题套路，尚未展现出质的推理范式跃迁。

真正改变学界传统认知的是 DeepSeek 团队提出的 DeepSeek-R1-Zero[3]。长期以来，后训练领域普遍默认“必须先用人工或强模型撰写的思维链数据开展监督微调教会模型如何一步步推导，随后才能用强化学习做补充性校准”。DeepSeek-R1-Zero 摒弃了这一前提，尝试直接在未经任何监督微调的纯预训练基座模型 DeepSeek-V3-Base（6710 亿总参数混合专家架构）上启动大规模 GRPO 强化学习，整个训练过程不提供任何人工解题步骤示范，不训练任何神经网络奖励模型，仅依靠最终答案准确性规则奖励与简单的 <think> 标签格式奖励驱动数千步在线迭代[3]。

图 14 记录了这一纯强化学习实验极具代表性的演化过程[3]。随着训练步数推进，DeepSeek-R1-Zero 在 AIME 2024 竞赛基准上的单次采样准确率从 15.6%15.6\%15.6% 持续上升至 71.0%71.0\%71.0%（延长训练后达 77.9%77.9\%77.9%），配合多数投票达到 86.7%86.7\%86.7%。比分数提升更重要的发现在于图 14 右侧的生成长度曲线：尽管奖励函数中没有任何鼓励增加字数的条款，模型为了在复杂多步推理中拿到终端正确奖励，自发学会了在 <think> 标签内大幅延长推导篇幅，按题目实际复杂度动态分配测试时计算量。在训练中后期，模型输出中频繁出现暂停复核（如在中间步骤自发生成“Wait, let me re-evaluate”）、识别前文计算矛盾、否定已有错误假设并切换新解题路径等反思修正行为（原论文将其称为“Aha Moment”）[3]。这一结果有力证明，大规模预训练基座内部已蕴含着丰富的逻辑推演先验，纯粹的客观结果强化学习足以在不依赖人工过程示范的前提下激发并组织复杂的长链推理机制。

然而，纯粹的“零监督微调”路线也付出了明显的使用体验代价。由于奖励函数只关心最终框内答案是否正确而对思考过程本身的语言形态毫无约束，DeepSeek-R1-Zero 生成的思维链普遍存在可读性差、排版杂乱的问题，尤为突出的是中英文等多语种词汇在同一段推导中频繁混杂切换，且该模型缺乏在非推理类开放任务（如角色扮演、创意写作与安全合规交互）上的基本对齐能力[3]。为了保留纯强化学习强大的推理涌现能力，同时彻底解决可读性与通用任务适用性缺陷，团队进一步设计了融合冷启动数据与多轮迭代的四阶段训练流水线，构建出旗舰模型 DeepSeek-R1[3]，其完整流程如图 15 所示。

剖析图 15 中的四个阶段可以清晰看出工业界顶级推理模型对监督学习与强化学习各自边界的精准拿捏[3]。第一阶段为冷启动监督微调（Cold Start）：收集数千条格式规范、包含末尾可读总结的高质量长思维链样本微调 DeepSeek-V3-Base，使模型在进入高成本强化学习之前即掌握人类易读的思考排版规范，避免了 R1-Zero 早期的无序探索震荡。第二阶段为面向推理的强化学习（Reasoning-oriented RL）：在数学、编程、科学与逻辑推理任务上执行与 R1-Zero 相同的大规模规则奖励 GRPO 训练，并额外引入一项统计目标语言词汇占比的“语言一致性奖励”（Language Consistency Reward）——消融实验表明，该约束虽使竞赛准确率出现极轻微折损，却彻底消除了中英文混杂顽疾，大幅改善了人类阅读体验。第三阶段为拒绝采样与全领域监督微调（Rejection Sampling and SFT）：当第二阶段推理强化学习收敛后，利用所得强推理检查点对海量提示多次采样，结合规则验证器与生成式评判模型筛除含错或混杂轨迹，精选出约 60 万条高质量推理样本，再与约 20 万条写作、事实问答、翻译及自我认知等非推理通用监督数据混合，重新对基座模型 DeepSeek-V3-Base 执行两轮全量监督微调，从而将强化学习探索出的高阶推理能力平滑迁移至具备完备通用能力的单一模型中。第四阶段为全场景强化学习（RL for All Scenarios）：在推理类提示上继续沿用客观规则验证奖励，而在通用开放类提示上引入捕捉人类有用性与安全性偏好的奖励模型开展最终对齐，使模型同时在竞赛推理与日常助手评估上达到顶尖水准。此外，DeepSeek-R1 还揭示了一条重要衍生规律：利用其生成的 80 万条高质量推理轨迹直接对 15 亿至 320 亿参数的中小规模开源基座做监督微调（知识蒸馏），所得性能远超直接在同等小规模基座上从零运行强化学习的结果，这表明小尺寸模型自身探索容量有限，先通过强模型轨迹转移高阶推理模式再辅以强化学习，是更具性价比的能力构建路径[3]。

4.4 优化方法的改进：DAPO 与 Dr. GRPO

随着学术界与开源社区纷纷尝试在公开权重模型（如 Qwen2.5-32B 等）上复现 DeepSeek-R1-Zero 式的长链推理强化学习，研究者很快发现：直接套用式 (14) 与式 (15) 给出的原始 GRPO 公式，训练过程往往在几百步后便陷入停滞甚至中途崩溃，远未达到理想性能上限。围绕“原始 GRPO 在大规模长序列 RLVR 训练中究竟存在哪些优化缺陷”，Yu 等人提出的解耦截断与动态采样策略优化（DAPO）[11]与 Liu 等人提出的无偏群组相对策略优化（Dr. GRPO）[12]分别从工程可扩展性与目标函数数学无偏性两个互补视角给出了深刻诊断与关键修正。

DAPO[11]在以 Qwen2.5-32B 基座复现数学竞赛强化学习时观察到，朴素 GRPO 在 AIME 2024 上仅能收敛至 30%30\%30% 准确率，其核心问题集中在策略熵过早坍缩、零优势样本浪费算力以及序列级损失加权失衡三个方面。首先，如图 16 右侧蓝线所示，朴素 GRPO 训练开始后不久，策略输出分布的条件熵便急剧跌向零点，这意味着模型迅速将概率集中到极少数固定表述上，彻底丧失了探索多样化解题思路的能力。为什么标准对称截断区间 [1−ε,1+ε][1-\varepsilon, 1+\varepsilon][1−ε,1+ε]（如 ε=0.2\varepsilon = 0.2ε=0.2）会诱发熵坍缩？DAPO 指出这是由概率比乘性截断对高概率 token 与低概率 token 的极度不对称限制造成的：对于一个旧概率 πθold=0.9\pi_{\theta_{\mathrm{old}}} = 0.9πθold​​=0.9 的高频常规 token，上限 1+0.2=1.21 + 0.2 = 1.21+0.2=1.2 允许其单步更新后概率直接达到 1.01.01.0；但对于一个旧概率仅为 πθold=0.01\pi_{\theta_{\mathrm{old}}} = 0.01πθold​​=0.01 的低概率反思或转折探索 token，即便它成功引导出了正确解答，上限 1.21.21.2 也将其单步更新后的新概率严格限制在 0.0120.0120.012 以内，导致高概率常规路径迅速占据主导概率，低概率探索 token 的概率难以有效增长[11]。

5 RLHF 与 RLVR 的比较及互补关系

5.1 奖励来源、数据需求与适用任务

站在大语言模型后训练全局架构的高度审视，RLHF 与 RLVR 并非后者简单淘汰前者的线性替代关系，而是针对两类截然不同的任务评估属性演化出的互补技术范式。要准确把握二者的边界，需要从奖励信号来源、核心数据需求、可承载的强化学习算力规模以及适用任务谱系四个相互关联的维度进行系统对比[1,6,3,2]。

在奖励信号来源上，RLHF（包括显式奖励模型 PPO 与隐式奖励 DPO）的评估依据来自人类的主观综合价值判断。它通过参数化的神经网络去逼近人类标注群体在比较两条回复时表现出的潜在偏好分布，输出的是反映相对满意度的连续标量预测值[4,1,5]。相反，标准 RLVR 的评估依据完全独立于主观感受，直接来自针对任务客观真值编写的确定性计算机检验程序（如符号代数等价判定器、代码执行沙箱及格式语法解析器），输出的是绝对客观的离散通过信号或精确测试通过率[6,3]。

这种奖励来源的本质差异直接改变了后训练阶段的数据工程重心。RLHF 的主要数据开销集中在采集高质量、覆盖广泛指令意图的人类成对偏好标注三元组 (x,yw,yl)(x, y_w, y_l)(x,yw​,yl​) 上：提示 xxx 本身甚至无需附带任何标准答案，但每一对模型生成的候选回复都必须经过人工或高能力教师模型的审阅排序；一旦模型迭代升级导致生成分布显著改变，原有的离线偏好集就会面临过时风险，往往需要重新采样与标注[1,10]。而在 RLVR 中，训练过程彻底免去了对模型生成过程与输出结果的人工逐条审阅，数据构建的重心前移到了“高质量可验证问题库与高覆盖率检验标准”的收集与清洗上，即构建大规模提示—真值对 (x,a)(x, a)(x,a) 或提示—单元测试集[6,3,11]。只要题目难度校准得当且标准答案或测试用例准确无误，同一批题库就可以支撑策略模型在线自主采样数百万条轨迹反复试错而不产生任何边际人工标注费用。

由此进一步决定了两者在适用任务范围与强化学习优化深度上的显著分工。RLHF 天然适用于那些缺乏唯一客观标准答案、但人类对其表达质量有明确感知的开放域交互任务，典型代表包括日常多轮对话、长文档摘要提炼、文学创意写作、职场邮件润色、语气风格定制以及涉及伦理价值权衡的安全拒答任务[1,5]。在这类任务中，优化目标主要是调整已有知识的表述组织方式与安全边界，通常只需数百步中等强度的强化学习或一至两轮偏好优化即可收敛。反之，RLVR 则专精于具备严密逻辑结构与客观真伪判据的复杂求解任务，涵盖竞赛级数学推导、算法与系统代码生成、科学计算推理、形式化定理证明、复杂逻辑谜题以及带严格结构化输出要求的工具调用与指令遵循任务[6,3,16]。在这类任务中，模型不仅需要调整表面表述，更需要通过数千步高强度在线探索重构内部多步推理策略。简言之，RLHF 解决的是“如何使模型按照符合人类交流习惯与安全规范的方式表达”，而 RLVR 解决的是“如何使模型通过深度思考攻克客观高难度复杂问题”。

5.2 结果监督与过程监督：反馈粒度的另一条划分轴

在对比 RLHF 与 RLVR 时，文献中常常还会交织出现另一组重要概念：结果监督（Outcome Supervision）与过程监督（Process Supervision）。必须明确指出的是，RLHF 与 RLVR 是沿着“奖励信号来源于主观偏好模型还是客观检验规则”这一维度划分的，而结果监督与过程监督则是沿着一条与之正交的“反馈信号在生成序列时间轴上的稠密粒度”维度划分的[13,7,2]。理解这两条划分轴的交汇与取舍，对于洞察现代推理模型演进逻辑至关重要。

为什么在客观推理任务中会提出过程监督？前文提到，标准 RLVR 仅根据模型在序列最末端给出的最终答案对错发放单一标量奖励，这属于典型的结果监督。Lightman 等人在开创性工作《Let's Verify Step by Step》[13]中敏锐指出，仅依赖最终结果反馈在复杂多步数学推理中面临双重隐患：其一是“错误过程导出正确结果”的虚假正例问题（False Positives），例如模型在中间两步推导中犯了方向相反的符号错误却碰巧抵消得到了正确数值，结果监督会无差别地奖励这些包含逻辑谬误的步骤；其二是长序列信度分配模糊，当一段包含二十步推导的解答因第十五步算错而最终得零分时，终端结果监督会将前十四步完全正确的关键构思一并惩罚。

为了精细化定位推理链中的具体成败节点，Lightman 等人构建了包含 80 万条人工步骤级正确性标注的数学推理数据集 PRM800K，系统对比了仅由最终答案训练的结果奖励模型（Outcome-supervised Reward Model，简称 ORM）与由人工逐步标注训练的过程奖励模型（Process-supervised Reward Model，简称 PRM）[13]。在 PRM 中，每当模型生成一个以换行符分隔的推理步骤，奖励网络便立即预测该步骤在当前上下文中是否正确，整条解答的综合评分由各步骤正确概率的连乘积（或最小值）给出；为了降低昂贵的专家标注成本，作者还设计了主动学习（Active Learning）筛选策略，专门挑选那些“令当前模型给出高置信度但最终答案实际上算错”的极具迷惑性样本交由人类标注，实现了 2.62.62.6 倍的数据效率提升[13]。

如图 18 所示，在基于候选重排序（Best-of-NNN）的推理测试时搜索评估中，过程监督展现出了压倒性优势：随着采样候选数 NNN 增加到 186018601860，多数投票准确率较早停滞在 69.6%69.6\%69.6%，ORM 提升至 72.4%72.4\%72.4% 但曲线趋缓，而 PRM 则一路攀升至 78.2%78.2\%78.2%，且候选池越大领先幅度越显著[13]。这是因为当候选池中混入大量凑巧蒙对答案的伪正确解答时，唯独能够逐行甄别推理有效性的 PRM 可以精准筛出逻辑真正严密的解法。后续 DeepSeekMath[7]等工作也尝试利用无需人工标注的蒙特卡洛树展开成功率自动构造步骤级 PRM 来配合 GRPO 训练。

然而，一个值得深入分析的技术转折在于：当研究从测试时重排序走向以 DeepSeek-R1[3]为代表的超大规模在线强化学习训练时，最终取得突破性进展的恰恰是仅依赖最终结果的可验证结果监督（RLVR），而非步骤级神经网络过程奖励模型（PRM）。DeepSeek-R1 团队在专门记录的对比实验中深入剖析了放弃神经 PRM 的三大根本原因[3]：第一，在自由演化的自然语言思维链中，模型常常将猜想、试算与反证交织在同一句话里，难以客观界定清晰的步骤切分边界，更难以判定某次探索步骤究竟是有益尝试还是错误推导；第二，无论是雇佣人类专家逐步标注（在严密质检的 PRM800K 中仍存在约 20%20\%20% 的人工噪声[13]）还是在每一步额外展开数十次蒙特卡洛采样估计价值，其标注与计算开销都限制了算法向更广泛问题集扩展；第三也是最关键的一点，只要过程奖励是由参数化神经网络给出的预测分值，一旦将其接入数千步高强度在线强化学习循环，策略模型就会迅速针对 PRM 产生奖励欺骗——例如不断重复输出“显而易见，由题意可知”等不会出错的套话来获取每一步的高过程得分，反而丧失了攻克难题的实际能力[3]。这一发展历程揭示出一条重要认识：在大规模强化学习参数优化中，奖励信号的抗欺骗可靠性远比反馈信号的时间步稠密性更为关键；只要终端结果验证精准无偏且基座模型具备基本逻辑先验，稀疏的结果级 RLVR 同样能够在大量采样对比中隐式完成步骤级信度分配[15]。

5.3 奖励可靠性

由过程监督与结果监督的实践分野进一步延伸，我们可以看到“奖励可靠性（Reward Reliability）”实际上构成了制约强化学习后训练能否持续扩展（RL Scaling）的首要决定因素。在预训练阶段，增大算力与数据量之所以能稳定换取更低的交叉熵损失，是因为真实文本 token 本身就是无偏的监督目标；而在强化学习阶段，策略模型会主动调整自身分布去搜寻奖励函数的最大值点，奖励函数中哪怕微小的评估漏洞，在高强度优化压力下都会被显著放大并导致生成分布扭曲[8,3]。

图 19 直观展示了 DeepSeek 团队在早期实验中使用大规模神经网络奖励模型训练推理策略时观测到的真实退化曲线[3]。可以看到，在前两三百个训练步内，神经奖励模型得分（蓝色圆点曲线）与 CodeForces 真实代码测试通过率（红色菱形折线）尚能保持一定协同增长；但越过临界点后，策略模型迅速利用了神经奖励模型的判别偏差，通过生成看似结构复杂实则无法通过边界测试的代码持续推高代理奖励分值，导致真实竞赛通过率急剧下跌，印证了第 3.4 节 Gao 等人[8]理论刻画的过度优化曲线。若想通过重新采集当前策略样本不断重训奖励模型来修补漏洞，不仅会使工程管线变得复杂脆弱，还会引发策略与奖励模型交替震荡的不稳定动态。与之相印证，Tülu 3[6]在受控消融实验中曾尝试将通用人类偏好奖励模型的连续打分与确定性数学验证器的二值奖励线性相加共同指导 PPO 训练，结果发现混入偏好奖励模型后模型的最终数学解题准确率反而明显低于纯粹使用二值可验证奖励的基线，原因正在于连续偏好打分的方差掩盖了精确的真伪边界，为策略模型提供了无需做对题目也能涨分的非目标优化途径。

当然，客观分析奖励可靠性，同样不能将现有的手工规则验证器视作毫无局限的理想判据。规则验证器的核心优势在于极低的“假阳性率（False Positive Rate）”——在覆盖完备的多个高难度单元测试用例或非平凡精确数值匹配下，错误代码与错误算式极难通过核验，从而阻断了恶性奖励欺骗。但与此同时，手工编写的规则解析器在面对复杂多变的表达形式时往往存在显著的“假阴性率（False Negative Rate）”与覆盖局限[6,19]。例如，当标准答案写为 22\frac{\sqrt{2}}{2}22​​ 而模型输出等价的 0.70710.70710.7071 或带有物理量纲说明的完整句子但未被规则库覆盖时，僵硬的字符串或符号规则会将其误判为零分；在跨学科自由简答（如医学诊断分析或经济学机制阐述）中，强行使用精确匹配规则甚至会迫使模型为了迎合僵化词面而丢失实质推理内容，导致训练数据越多性能反而越差[19]。反之，在选项极少的选择题或答案仅为小整数的题目上，纯结果规则验证又会面临偶然猜中答案带来的假阳性干扰[15]。因此，奖励可靠性的本质要求既不是盲目排斥模型参与验证，也不是局限于简单字符串规则，而是确保验证信号与真实任务目标之间不存在可被策略梯度利用的系统性偏差。

5.4 偏好对齐与可验证任务学习的结合

既然 RLVR 凭借高可靠性的客观验证赋予模型深层逻辑推理能力，而 RLHF（及 DPO）凭借灵活的人类偏好拟合赋予模型自然流畅的表达风格、多领域指令遵循能力与安全合规边界，那么在一个面向真实用户部署的通用大语言模型中，如何将这两类强化学习机制有机结合起来，使其既具备严密可靠的多步逻辑推理能力，又保持自然清晰、安全合规的开放交互表现，便成为现代后训练流水线设计的核心课题[6,3,2]。

从现有代表性系统的实践来看，融合偏好对齐与可验证任务学习主要形成了两条成熟路径，二者在阶段先后顺序与分布耦合机制上各有明确考量。第一条路径是以 Tülu 3[6]为代表的“先偏好对齐、后可验证强化”串联路径，即依次执行 SFT→DPO→RLVR\mathrm{SFT} \rightarrow \mathrm{DPO} \rightarrow \mathrm{RLVR}SFT→DPO→RLVR。在这一路径中，研究者重点关注的一个核心问题是：在进入最后阶段 RLVR 之前先做 DPO 偏好对齐，究竟会因为收紧输出分布而妨碍数学探索，还是能为 RLVR 提供更优质的初始策略起点？

图 20 给出了清晰的实验答案[6]。对比直接从 Tülu 3 SFT 模型启动 RLVR（同色系浅色曲线）与从 Tülu 3 DPO 模型启动 RLVR（深色饱和曲线）可以发现，DPO 初始化不仅在初始时刻就具备更高的可验证奖励得分，而且在完全相同的强化学习步数与多组 KL 惩罚系数设置下，始终维持在更高的奖励平台并对应更优的测试准确率（左图），同时其相对于参考策略的累积 KL 散度偏移不到 SFT 初始化方案的一半（中图），回复长度也保持在更为紧凑平稳的区间（右图）。其内在机理在于，DPO 阶段已经剔除了监督微调模型中大量格式松散、逻辑断裂的低质量生成分支，使 RLVR 无需耗费算力去重新修正基础回复规范，只需在相对紧凑的高质量分布邻域内微调概率即可锁定正确解题路径，同时较小的 KL 偏移也最大限度保留了前一阶段已经建立好的通用对话胜率与安全性表现[6]。

第二条路径则是以 DeepSeek-R1[3]为代表的“先专项长链 RLVR 突破推理上限、经拒绝采样融合通用 SFT、最后开展分域混合奖励对齐”的深度协同路径（参见前文图 15）。为什么在训练超强长思维链推理模型时不能简单套用第一条路径直接在常规 DPO 对齐模型后面做轻量微调？因为常规人类偏好对话普遍偏爱简洁凝练的数百词回复，经过强偏好对齐的模型输出分布往往已被锁定在短回复模式上，很难再通过数千步自由探索生长出长达上万 token 的反思型思维链。因此，DeepSeek-R1 选择在冷启动后首先投入绝大部分强化学习算力运行纯粹的规则驱动 RLVR，待深层推理能力充分涌现后，通过拒绝采样将推理轨迹与通用写作、安全数据统一蒸馏回同一个监督模型，最后在第四阶段“全场景强化学习”中实施分域精准施策[3]：对于数学、代码与逻辑提示，依然严格调用确定性规则验证器计算奖励；对于开放式问答与创意辅助提示，则调用偏好奖励模型与安全奖励模型评估回复质量（尤为关键的工程细节是，有用性奖励模型仅对 <answer> 摘要总结部分打分而不干预 <think> 内部自由推理过程，且该混合对齐阶段严格控制在最后数百步内完成，彻底杜绝神经奖励模型侵蚀推理核心逻辑）。这两条路径共同证明，客观可验证奖励与主观人类偏好并非彼此排斥，通过在训练阶段顺序与作用文本区间上实施合理隔离与衔接，完全可以实现严谨推理深度与人类交互体验的协同增益。

6 研究进展与关键争论：RLVR 究竟提升了什么

6.1 推理能力的评估

随着以 DeepSeek-R1 为代表的 RLVR 模型在各大数学与编程榜单上取得突破性进展，学术界迅速转向了一个更为本质的科学追问：经过可验证奖励强化学习训练后，模型在基准测试上的大幅涨分，究竟意味着模型真正习得了超越预训练基座的新推理能力，还是仅仅把基座模型原本就已经会做、但单次采样不易抽中的正确解法集中到了高概率区域？要客观回答这一问题，首先必须审视推理能力本身的量化评估方法，因为不同的评测指标测量的是策略分布截然不同的统计侧面[14,15,2]。

在常规模型评测中，最广泛使用的指标是单次采样准确率（Pass@1\mathrm{Pass@}1Pass@1，通常在对多条独立采样取均值意义下报告以降低评估方差）。Pass@1\mathrm{Pass@}1Pass@1 度量的是模型在单次生成尝试中直接命中正确答案的期望概率，直接反映了模型在实际部署时的单次推理可靠性与采样效率。然而，Pass@1\mathrm{Pass@}1Pass@1 无法区分“从完全不会变为会做”与“将原本 5%5\%5% 的答对概率提高到 80%80\%80%”这两种截然不同的变化。为了探测一个策略模型潜在的推理能力上限（Capability Boundary），Yue 等人[14]与 Wen 等人[15]系统引入了代码生成领域经典的多次采样通过率指标 Pass@k\mathrm{Pass@}kPass@k：针对同一问题提示 qqq 独立采样 kkk 条候选回复，只要其中至少存在一条回复最终答案正确，即判定模型在该预算 kkk 下能够解决该问题。为了消除直接抽样 kkk 次带来的随机波动，实际评测时通常先针对每道题生成总数 GGG（G≥kG \ge kG≥k）条回复，统计其中最终答案正确的样本个数 C=∑i=1GIAns(ai)C = \sum_{i=1}^G I_{\mathrm{Ans}}(a_i)C=∑i=1G​IAns​(ai​)，再采用无偏组合估计量计算 Pass@k\mathrm{Pass@}kPass@k[14,15]：

然而，Wen 等人[15]通过深入人工核查发现，直接照搬仅检查最终答案对错的传统 Pass@k\mathrm{Pass@}kPass@k（式 (18) 左式）来评估大采样预算下的数学基座模型，会产生严重的系统性高估偏差。原因在于，许多高难度数学竞赛题的最终答案形式极为简单（例如 AIME 竞赛规定所有题目答案均为 000000000 至 999999999 之间的整数）：当对一个未经对齐的预训练基座模型强行独立采样 102410241024 次时，模型会生成五花八门包含严重逻辑跳跃、公式张冠李戴甚至中途算错的思维链，但只要其中哪怕有一次在错误的推导末尾凑巧输出了目标整数，传统 Pass@k\mathrm{Pass@}kPass@k 就会认定“基座模型本来就会解这道题”[15]。

6.2 采样效率提升与推理能力边界扩展之争

依托上述多维评估体系，近年来围绕“RLVR 究竟提升了什么”展开了后训练领域最核心的一场学术争论，研究结论经历了从“分布锐化论”到“有条件的能力边界扩展论”的逐步深化[14,16,15,2]。

争论的起点是 Yue 等人发表的系统性实证研究《Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?》[14]。作者在涵盖 Qwen2.5、Llama-3.1 与 DeepSeekMath 等多个模型家族以及数学、代码生成、视觉多模态推理的广泛基准上，对比了基座模型与主流开源 RLVR 训练后模型从 k=1k=1k=1 到 k=1024k=1024k=1024 的完整 Pass@k\mathrm{Pass@}kPass@k 曲线。

如图 22 所示，实验呈现出一个高度一致的反直觉规律：当 k=1k=1k=1 时，RLVR 模型的准确率显著高于基座模型；但随着 kkk 不断增大，基座模型的 Pass@k\mathrm{Pass@}kPass@k 曲线以更陡峭的斜率快速攀升，通常在 k=64k=64k=64 至 256256256 之间便追平并反超了经过强化学习训练的模型[14]。更进一步的子集归属分析显示，RLVR 模型能够解出的题目几乎完全包含在基座模型多次采样可解题目的子集之内；相比之下，用更强大的外部模型轨迹对基座执行知识蒸馏（Distillation），则能在所有 kkk 值上全面抬高整条 Pass@k\mathrm{Pass@}kPass@k 曲线。据此，Yue 等人提出“采样效率提升假说”：当前 RLVR 并未让模型习得超越预训练先验范围的新推理知识，而仅仅是将原本分散在广阔输出空间中的概率质量集中到了基座模型本就存在的正确路径上，即以牺牲输出分布多样性与大 kkk 覆盖上限为代价，换取了单次采样的准确性[14]。

这一尖锐结论迅速激发了后续更为深入的反驳与修正研究，其中最具代表性的是 Liu 等人提出的延长强化学习框架 ProRL[16]与 Wen 等人的隐式正确推理激励理论[15]。他们通过严密实验指出，Yue 等人之所以观测到大 kkk 下能力边界收缩，主要受制于三项实验设定局限：一是评测数学题时未剔除基座模型在千次采样下的凑巧猜对现象；二是所考察的开源 RLVR 模型大多只在单一数学领域上训练了寥寥数百步便提前终止，尚未进入深层探索阶段；三是所选数学基准与预训练语料重合度极高，基座模型初始大 kkk 通过率本就接近饱和[16,15]。

当消除上述三项混淆因素后，实验图景发生了根本改观。首先，在评估维度上，Wen 等人[15]证明（见图 21 右图），一旦改用严格核验推导过程的 CoT-Pass@k\mathrm{CoT\text{-}Pass@}kCoT-Pass@k 并在无预训练污染的 AIME 2025 及高难度代码基准 LiveCodeBench v1–v6 上评测，经过充分训练的 RLVR 模型（如 DAPO-Qwen-32B 与 AceReason-Nemotron-7B）即便在 k=1024k=1024k=1024 处依然与基座模型保持着显著且稳定的正向差距。为了从理论上解释“为什么只奖励最终答案对错就能促使中间推导变正确”，Wen 等人建立了基于“逻辑先验（Logic Prior）”的梯度定理[15]：只要预训练赋予模型最基本的逻辑区分先验，使得正确思维链导出正确答案的条件概率严格高于错误思维链凑巧蒙对答案的条件概率，即

那么在任意可学习提示组上，正确思维链获得的期望 GRPO 优势严格为正（E[A^(y)∣ICoT(c)=1]>0\mathbb{E}[\hat{A}(y) \mid I_{\mathrm{CoT}}(c)=1] > 0E[A^(y)∣ICoT​(c)=1]>0），错误思维链的期望优势严格为负（E[A^(y)∣ICoT(c)=0]<0\mathbb{E}[\hat{A}(y) \mid I_{\mathrm{CoT}}(c)=0] < 0E[A^(y)∣ICoT​(c)=0]<0）。这意味着单步策略梯度更新必然单调推高生成严密逻辑推导链的概率并压低胡乱猜测的概率；将 RLVR 训练后的思维链提取出来重新微调原始基座，能够复现出基座自身采样数据根本无法企及的测试集泛化能力，直接证实推理过程质量发生了质的跃升[15]。

其次，在任务先验与训练步数维度上，ProRL[16]在涵盖数学、代码、科学推理、逻辑谜题与指令遵循的 13.6 万道多领域题目上将 15 亿参数模型持续训练超过 2000 步，统一调和了此前的矛盾观测。如图 23 所示，不同任务在长程 RLVR 下的 Pass@k\mathrm{Pass@}kPass@k 变化并非单一模式，而是分化为边界收缩（Diminish）、早期饱和（Plateau）与持续扩展（Sustained）三种清晰形态[16]：在基座模型预训练覆盖充分、初始 Pass@128\mathrm{Pass@}128Pass@128 本就极高的常规数学任务上，分布锐化效应占主导，大 kkk 分数略有回落；但在基座模型初始能力薄弱、与预训练语料重叠度低（创造性指数 Creativity Index 更高）的复杂代码竞赛与逻辑组合谜题上，RLVR 展现出显著的边界扩展效应——甚至在多类基座模型连续抽样 256256256 次通过率恒为 0%0\%0% 的全新任务及分布外测试任务上，经过长程 ProRL 训练的模型取得了接近 100%100\%100% 的通过率[16]。综合两派证据可以得出公允的科学结论：RLVR 虽然无法凭空捏造预训练词表与基础常识之外的全新事实知识，但当基座模型已经具备原子级推理原语且任务留有充足组合空间时，长程、高质量的 RLVR 完全能够学会将这些原子技能按全新方式长程组合，从而实质性扩展复杂问题求解的能力边界。

6.3 Continuous Learning 的条件：探索、训练时长与隐式课程

上述争论进一步引出了一个决定实际训练成败的关键问题：为什么普通 RLVR 训练往往在几百步后就因分布固化和梯度消失而停滞，而在另一些设定下模型却能维持数千步的持续强化学习精进？需要说明的是，此处目录所称的 Continuous Learning，在推理模型强化学习语境下特指模型在长程训练过程中不发生性能坍缩、随训练算力投入持续提升推理表现的持续强化学习优化（Prolonged RL），而非传统多任务序列学习中旨在克服灾难性遗忘的连续学习[16,18,17]。综合最新理论与大规模实证研究，实现这种长程持续学习必须同时满足 token 级有效探索维持、充足训练时长配合参考基准动态重置以及平滑混合难度诱导隐式课程这三项核心条件。

第一个条件是精准保护有意义的低概率探索 token，而非盲目推高全局策略熵。如前文所述，长程 RLVR 停滞的最典型征兆是策略熵快速归零，但 Huang 等人在 ACL 2026 发表的大规模实证研究[17]揭示了一个反常现象：如果在 GRPO 损失中简单加上传统的全局最大熵奖励项（Entropy Bonus），模型不仅没有变得更能探索，反而比原始 GRPO 更快发生训练崩溃（见图 24 子图 b）。为什么全局增熵会适得其反？通过对预测词表尾部分布的细致统计，作者发现长思维链之所以能够退出受阻推导并转向新的候选解法分支，关键依赖于诸如“wait”“however”“perhaps”这类触发反思与路径切换的低概率探索 token；然而在词表概率极低的长尾末端，除了这些有语义价值的探索 token 外，还分布着数以万计与当前数学上下文毫无关系的纯噪声 token（如无关名词“cost”“fine”）[17]。标准 GRPO 在遭遇负优势样本时会无差别地将有价值的低概率探索 token 压制到零；而无选择性的全局熵损失则会把大量无关噪声 token 的采样概率大幅抬高（图 24 子图 d），直接破坏推理连贯性。

第二个条件是突破短程步数限制，并在长程训练中配合动态参考策略重置机制。ProRL[16]的研究表明，模型从掌握浅层格式调整到真正重组深层多步推理策略，往往需要跨越上千步乃至两千步以上的持续迭代更新。但在漫长的训练周期内，固定不变的初始参考策略 πref\pi_{\mathrm{ref}}πref​ 会引发新的矛盾：如第 2.3 节所述，完全去掉 KL 惩罚容易导致已具备良好思维链基础的模型过早丢失分布多样性，而如果一直以最初的检查点作为参考分布基准，随着在线策略不断演化，KL 散度惩罚项将在总损失中占据越来越大的比重，最终过度限制参数更新步长使后期训练陷入停滞[16]。对此，ProRL 引入了周期性参考策略硬重置（Reference Policy Reset）机制：每当监测到验证集性能进入平台期时，便直接将参考策略更新为当前最新的在线策略快照，并同步重新初始化优化器动量状态[16]。这一操作在局部维持了 KL 分布稳定约束的同时，允许策略分布通过多轮分阶段推进不断向高阶解空间深处拓展。

第三个也是从数据动力学角度最为关键的条件，是训练数据难度谱系的平滑连续性所诱导的“隐式课程（Implicit Curriculum）”。长期受到理论界关注的一个核心问题是：对于需要连续正确执行 LLL 步组合操作的长跨度推理任务，初始近似均匀的注意力机制面对终端二值结果奖励时，正确轨迹的采样概率与策略梯度模长均以 d−Ω(L)d^{-\Omega(L)}d−Ω(L) 的指数级速度衰减为零（形成指数级平坦梯度区）[18]；既然初始梯度几乎为零，现实中并未人工按难度排序题目的大规模 RLVR 为何没有停留在零梯度初始区，反而能逐步攻克长跨度难题？

Huang 等人（2026）[18]借助有限群上的傅里叶分析工具，在具备预训练单步原子技能的 Transformer 模型上严格证明了混合难度分布下的训练动力学定理，阐明了这一现象的内在机理。理论与实证结果（见图 25）共同表明：当训练数据集自然包含从短跨度到长跨度的混合难度样本 {L1,L2,…,LK}\{L_1, L_2, \dots, L_K\}{L1​,L2​,…,LK​} 时，无需任何外部显式课程调度，策略梯度优化会自发涌现出由易到难的隐式课程[18]。具体而言，处于临界短跨度以内的简单题目首先获得非零终端奖励并率先收敛，其梯度更新在持续锐化模型内部注意力关联表征的过程中，会同步抬高相邻稍难问题 Lk+1L_{k+1}Lk+1​ 的偶然成功概率，使其脱离指数平坦区进入有效学习前沿。尤为重要的是，这种自发课程的运转效率严格取决于相邻难度步长比 R=Lk+1/LkR = L_{k+1} / L_kR=Lk+1​/Lk​：当训练数据的难度谱足够稠密平滑（即 R=O(1)R = O(1)R=O(1)）时，简单任务在尚未完全饱和前便已将有效梯度平稳传递给下一难度层级，训练始终保持在模型当前“能力边缘（Edge of Competence）”连续推进；反之，若数据集中缺少中间过渡难度导致难度断层过大（R≫1R \gg 1R≫1），简单任务早已满分饱和（失去梯度），而高难任务仍处于随机猜题区，模型只能依靠简单任务残余的微弱特征锐化经历极其漫长的零奖励停滞平台，之后才可能突然触发文献中称为延迟泛化（Grokking）的陡峭相变跃迁，甚至长期停滞在零分[18]。这一理论不仅从数学上解释了 RLVR 训练中常见的长平台后突变现象，也指明了持续强化学习在数据侧的关键原则：构建覆盖连续难度梯度并实时聚焦能力前沿的训练题库，与改进优化算法同等重要。

6.4 从确定性验证到更广泛任务的奖励设计

尽管以符号计算引擎和代码单元测试为核心的确定性规则验证器在数学与编程领域取得了巨大成功，但如果大语言模型的强化学习后训练只能停留在具备封闭形式解或可执行代码的狭窄领域，其通往通用复杂科学推理与现实决策辅助的道路仍将受到明显限制。在临床医学鉴别诊断、法律条文适用分析、宏观经济学机制推演、心理学实验设计以及人文社科综合论述等更为广阔的知识密集型领域中，问题的解答天然呈现为自由文本形式（Free-Form Answers），既无法放进编译器运行，也无法通过几条正则表达式或符号化简规则穷尽所有语义等价的正确表述[19,2]。

更为严峻的是，Su 等人在 ACL 2026 发表的跨学科大规模实证研究[19]揭示了一个反直觉的退化现象：当试图将传统的精确字符串或规则匹配验证器强行推广到涵盖医学、法学、经济学、工程学等 48 个一级学科的大学专业简答基准 ExamQA 上时，随着多领域自由问答训练数据量从 2 万条扩充至 10 万条，规则驱动 RLVR 训练出的策略模型准确率不仅没有提升，反而从 26.2%26.2\%26.2% 一路下降至 16.9%16.9\%16.9%（见图 27 左图红色折线）[19]。其根源在于，自由文本领域中僵硬规则的假阴性率极高，大量推理严密但措辞与标准答案表面不一致的优质回答被误判为零分，迫使模型在更大规模数据上放弃实质性学科推理而去迎合零散的局部字面匹配，从而严重损毁了跨领域泛化能力。

那么，一旦越出严格结构化任务边界，难道我们只能退回第 3 节那种依赖高昂人工偏好标注且极易遭受奖励欺骗的传统 RLHF 奖励模型吗？Su 等人[19]提出了一条兼顾客观真值依据与语义灵活性的改进思路：传统无参考奖励模型之所以在专业领域不可靠，是因为要求模型在没有任何标准答案对照的情况下直接评判高深专业问题的对错；但如果我们为每道专业问题配备一份专家撰写的标准参考答案（Reference Answer）aaa，将验证器的任务从“开放式质量打分”转化为“对照给定标准答案 aaa 核查模型最终结论 yTy^TyT 是否在专业语义上等价正确”，那么现代强指令语言模型与人类专家评判之间便能达到极高的一致性（实测跨学科科恩一致性系数 Cohen's κ>0.81\kappa > 0.81κ>0.81，高校专业学科上超过 0.870.870.87）[19]。

7 总结与展望

回顾大语言模型强化学习后训练从 RLHF 到 RLVR 的完整演进历程，一条清晰的内在逻辑贯穿始终：自回归预训练通过海量语料上的下一 token 似然最大化为模型奠定了广博的知识表征与原子推理先验，而后训练阶段的核心使命，则是设计既符合目标任务本质、又能承受优化压力而不失真的反馈信号，引导模型在序列决策空间中自主重塑输出分布[1,3,2]。在这一演进脉络的起点上，针对日常开放域交互任务难以用确定性程序定义优劣的难题，RLHF 借助成对人类偏好比较与 Bradley-Terry 统计建模，首次打通了从人类主观判断到大规模语言模型策略梯度更新的闭环[4,1]；随后 DPO 利用 KL 正则化目标的闭式最优解消除了显式奖励建模与在线采样负担，使偏好对齐成为现代开源模型的普惠基础组件[5]。然而，受制于人类专家标注在复杂专业任务上的高昂成本，以及参数化代理奖励模型在分布偏移下必然触发的过度优化与奖励欺骗定律[8,10]，单纯依赖主观偏好拟合的路线难以通过持续扩大强化学习算力来攻克长跨度逻辑难题。

正是在克服代理奖励失真的直接驱动下，RLVR 通过回归客观真值检验实现了后训练范式的关键跃迁[6,7,3]。依托符号数学核验与代码单元测试等零拟合误差的确定性验证函数，配合省去庞大价值网络的群组相对策略优化（GRPO）[7]以及针对熵坍缩、零优势退化和长度归一化偏差的系统性修正（如 DAPO 与 Dr. GRPO）[11,12]，大语言模型首次展现出仅凭终端结果反馈即可自发演化出长思维链、自我验证与路径回溯等高阶推理行为的能力[3]。进一步围绕“RLVR 究竟提升了什么”的深入争论表明，单次采样效率提升与潜在推理边界扩展并非非此即彼的对立属性[14,16,15]：只要基座模型在预训练中掌握了必要的原子逻辑先验，同时在训练中满足精准保护低概率探索 token[17]、维持足够训练步数并动态更新参考分布基准[16]、以及构建连续平滑的混合难度数据谱系以触发由易到难的隐式课程传递[18]，稀疏的结果级强化学习便能超越单纯的概率锐化，实质性拓展复杂组合推理的能力上限；而将其与负责塑造表达可读性、通用指令遵循及安全边界的 RLHF 或 DPO 分阶段协同整合，则构成了当前旗舰级推理与对话通用模型的标准后训练范式[6,3]。

展望未来，大语言模型强化学习后训练仍处于快速演进之中，以下四个方向有望成为下一阶段突破的关键着力点。第一，在奖励与验证机制层面，研究重心正加速从单一回合的数学与封闭代码题，迈向更广阔的跨学科专业领域与开放式多轮交互环境[19,2]。一方面，如何结合专家参考答案、结构化评分细则（Rubrics）与具备显式先思考后评判能力的生成式奖励模型，在医学、法学、科学研究与工程设计等自由文本场景中提供既细腻又抗策略投机的软验证信号，仍需深入探索静态蒸馏之外的策略—验证器协同演化机制[19,2]；另一方面，在软件仓库级修复、网页信息检索与多模态工具操作等长周期智能体（Agentic RL）任务中，将真实外部环境的执行状态反馈转化为多步密集可验证奖励，将是释放现实世界生产力价值的重要途径[2]。

第二，在推理效率与测试时计算控制层面，克服无谓的长度膨胀与“过度思考”正变得日益紧迫[12,2]。当前长链推理模型面对简单算术或常识问题时仍常耗费数千 token 反复自检，带来高昂的线上推理延迟与能耗开销。未来不仅需要在优化器层面普遍落实无长度偏差的梯度估计[12]，更需要在奖励塑形与模型架构层面引入按题目真实复杂度自适应分配思考预算的机制，乃至探索在连续隐状态空间（Latent Space）内完成紧凑推理计算而仅按需输出简洁人类可读解释的新型训练范式[2]。

第三，在预训练先验、数据课程与强化学习的联合设计层面，越来越多的证据表明强化学习的能力上限深刻依赖于基座模型预训练阶段的领域知识密度与逻辑原语质量[12,18]。未来的模型研发将不再把预训练、监督微调与强化学习视作割裂的串联工序，而是通过在线监测模型当前的“能力边缘”，动态合成或检索难度恰处于可学习前沿的过渡任务以消除隐式课程断层[18]，并在预训练阶段前瞻性注入有利于后续探索分支涌现的多样化推理语料[12,2]。第四，在大规模系统基础设施与持续演化算法层面，随着单次强化学习训练跨度向数千步、数万 token 上下文乃至多轮环境交互延伸，异构采样生成与参数梯度更新之间的负载不均衡与策略滞后（Off-Policyness）矛盾愈发突出[11,17,2]。发展支持异步流式采样、精细化 token 级分布正则化与跨周期稳定持续学习的下一代强化学习系统，同时将基于客观环境验证的能力进化（RLVR）与基于多元人类价值规范的安全对齐（RLHF）更加紧密、稳健地统一在同一理论与工程框架之下，将持续推动大语言模型向更可靠、更高效、更具通用求解深度的方向迈进。
